# OmniHubb

OmniHubb is the current working brand for the OmniHubb project.

## Included
- Consumer-facing website
- Redesigned OmniHubb homepage
- Existing product pages
- Gift cards, deals, cart/wishlist/account pages
- Nationwide local-business marketplace page
- Admin panel (`admin.html`)
- Node/Express backend (`server/server.js`)
- JSON data store for gift cards, categories, brands, deals and businesses
- Existing product images/assets

## Homepage
The homepage has been redesigned around the supplied marketplace reference:
- OmniHubb branding
- Gift-card hero
- Category navigation
- Best-selling gift cards
- Deal of the Day
- Trust/benefit strip
- Top Trending Deal
- Local Stores
- Exclusive Offers
- Refer & Earn
- Affiliate product preview

## Run locally
1. Install Node.js.
2. Run `npm install`.
3. Run `npm start` (or the script defined in package.json).
4. Open the local address shown by the server.

## Important
Affiliate URLs, payment credentials, production database credentials and third-party API keys are not included as live credentials. Add them through your production configuration before launch.
