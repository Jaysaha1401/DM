# DealMantra V2

DealMantra is being developed as an India-focused marketplace for discounted gift cards, affiliate deals and a future local-business marketplace.

## Current V2 frontend
- Marketplace-style responsive homepage inspired by the provided reference.
- Gift card catalogue UI.
- Affiliate deal catalogue with search/filter structure.
- Product detail pages.
- Wishlist and cart using browser localStorage.
- Account/login UI placeholder.
- Local-business partnership page.
- Future admin dashboard UI.
- Responsive desktop/tablet/mobile styling.

## Next architecture phases
1. Backend/API and database.
2. Real authentication and user accounts.
3. Gift-card provider integration and payment gateway.
4. Affiliate network/store integrations and tracking.
5. Admin CRUD for deals, brands, gift cards and businesses.
6. Local-business onboarding, promotions and branded gift cards.
7. Mobile app using the same backend/API.

This version is intentionally frontend-first. Payment, fulfilment, affiliate tracking and authentication are not simulated as real transactions.

## V2.1 backend foundation
This project now includes a dependency-free Node.js API in `server/`. See `BACKEND-SETUP.md` for local setup and API endpoints.
